开发者亦可在本地通过源码直接构建当前操作系统专属的桌面可执行分发包：

🍎 macOS 本地打包指令 (.dmg)
# 1. 进入 desktop 目录并安装依赖
cd desktop && npm install

# 2. 构建 Apple Silicon (M系列芯片) DMG 安装包
npm run dist:mac-arm64

# 3. 构建 Intel 芯片 DMG 安装包
npm run dist:mac-x64
🪟 Windows 本地打包指令 (.exe)
# 1. 进入 desktop 目录并安装依赖
cd desktop && npm install

# 2. 构建 Windows NSIS 安装向导版与便携版
npm run dist:win
🐍 Python 原生桌面模式 (无需 Node.js)
# 直接通过 PrismEra CLI 启动原生桌面窗口
python -m prismera desktop

# 或通过 Makefile 快捷启动
make desktop
💡 桌面客户端在启动时将自动拉起本地 Python 智能体网关，关闭应用时自动释放端口与系统资源。
